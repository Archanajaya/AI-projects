# 🎬 Gemini AI Movie Recommendation Chatbot

This project is a simple GenAI chatbot built using Python and Google Gemini API.

## Features
- Movie recommendations
- Genre-based suggestions
- AI-generated responses
- Knowledge-base chatbot

## Technologies Used
- Python
- Gemini API
- Prompt Engineering

## Example Questions
- Suggest action movies
- Recommend romance movies
- Best comedy films

## Future Improvements
- Streamlit UI
- Voice chatbot
- Movie database integration
